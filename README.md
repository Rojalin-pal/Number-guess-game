# 🧠 The Mind Guess — Number Mystery Game

An interactive, responsive number-guessing web game developed using **Python** and **Streamlit**. Players test their intuition by guessing a randomly generated number between 1 and 100 under a strict 60-second countdown and a 10-attempt limit.

🔗 **Live Demo:** [Click here to play the game](https://your-streamlit-app-link-here.streamlit.app)

---

## ✨ Features

- **Personalized Onboarding:** Welcome screen capturing custom player handles with zero credential barriers (no email/phone required).
- **Time-Trial Mode:** Real-time 60-second countdown with visual progress tracking.
- **Dynamic Feedback Loop:** Instant direction cues (Too High / Too Low) with persistent guess trail badges.
- **Responsive State Management:** Powered by Streamlit's `st.session_state` for round transitions, form field resets, and game status handling.
- **Victory Celebrations:** Dynamic particle effects (balloons & confetti) on successful deduction.
